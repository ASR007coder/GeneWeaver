# GeneWeaver

GPU-Accelerated CRISPR Off-Target Alignment Engine.

GeneWeaver is a high-performance bioinformatics project designed to accelerate genomic sequence alignment and CRISPR off-target detection using NVIDIA CUDA, Numba, BioPython, and Dask.

## Project Structure

- backend/ - Genomic processing, alignment algorithms, CUDA kernels, and distributed execution.
- frontend/ - Terminal-based monitoring dashboard and visualization.

## Technology Stack

- Python
- BioPython
- Numba CUDA
- Dask
- Textual
